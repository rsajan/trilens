Drop files here to add them to the Technical page's Library. Then run PUBLISH.bat.

What works:
  .md  .markdown  .docx  .pdf      shown as readable documents
  .csv  .xlsx  .xlsm               shown as tables (first 300 rows of each sheet)
  .html  .htm                      shown as a report (scripts are blocked)
  .png  .jpg  .gif  .webp  .svg    shown as images
  .txt  .py  .pine  .log  .json    shown as plain text

Files in this folder are NEVER uploaded as they are. They are packed into one file that is
encrypted with your password on this PC. Anyone without the password sees only random bytes.
